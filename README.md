# Carbon Code

Create beautiful, shareable code images inspired by Carbon. Choose a theme, language, background color, and padding, then export a PNG in one click.

## Live Demo
- https://carbon-code-ixl1.vercel.app

## Features
- Syntax highlighting for JavaScript, Python, and HTML
- Themes: Dark, Light, and Dracula
- Adjustable window color and padding
- Resizable editor area
- One-click PNG export

## Tech Stack
- React + Vite
- CodeMirror (UIW)
- html2canvas

## Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

### Lint
```bash
npm run lint
```

## Project Structure
```
src/
  components/    # UI components (editor, controls, window chrome)
  App.jsx        # App layout and state
```
